# Módulo 5 — Lenguajes de Marcas y Sistemas de Gestión de Información

**Empresa:** `VectorSec`

**Sector:** `Ciberseguridad` — `auditoría, pentesting y formación en seguridad informática`

**Consideraciones:** Este módulo contiene dos piezas con propósitos distintos — *se documentan por separado para que no se confundan entre sí*:

## Entregable oficial: [`xml/`](xml/)

Diseño de un documento **XML** de exportación de proyectos finalizados (con datos reales, reutilizados del Módulo 4), su **XSD** de validación, y evidencia real de validación **correcta** e **incorrecta** con `xmllint`. Detalle completo, explicación de la integración con el resto del proyecto y checklist en [`xml/README.md`](xml/README.md).

## Añadido práctico: [`web-corporativa/`](web-corporativa/)

Propuesta de página web corporativa de `VectorSec` (`index.html` + `styles.css`), pensada como ejemplo de **la cara visible de la empresa**: responsive (menú de hamburguesa en móvil/tablet), orientada a los 4 servicios ya definidos en el proyecto (mismos servicios del Módulo 4), con una identidad visual propia construida alrededor del vocabulario real de una auditoría de seguridad (severidad de hallazgos), en vez de clichés genéricos del sector.

Esta propuesta no forma parte del checklist oficial de este módulo (que exige específicamente **XML/XSD**), pero se incluye en el repositorio como **material de portfolio** adicional, *relevante para el Módulo 7*.
